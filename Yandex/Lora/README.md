# Проект: Эффективная настройка и адаптация LLM

## 📋 О проекте

Данный проект демонстрирует процесс эффективного дообучения большой языковой модели (LLM) с использованием метода **LoRA** (Low-Rank Adaptation) и **Supervised Fine-Tuning (SFT)**.

**Цель проекта:** Показать, как можно адаптировать предобученную языковую модель под конкретную задачу, используя минимальные вычислительные ресурсы, и оценить эффективность такого подхода.

---

## 🎯 Ключевые результаты

| Метрика | Baseline | После дообучения | Изменение |
|---------|----------|------------------|-----------|
| **Perplexity** | 4.62 | 2.95 | **-36.0%** ✅ |
| **ROUGE-1** | 0.0423 | 0.0369 | -12.6% |
| **ROUGE-L** | 0.1821 | 0.2032 | **+11.6%** ✅ |
| **BLEU** | 0.0000 | 0.0000 | — |

### 🎉 Главные достижения:
- **Perplexity улучшилась на 36%** — модель стала значительно лучше понимать и предсказывать текст
- **ROUGE-L вырос на 11.6%** — качество генерации заметно повысилось
- **Обучается только 0.43% параметров** — огромная экономия ресурсов
- **Размер адаптера: 35 MB** (вместо 3.4 GB полной модели) — экономия места >100x

## 🛠️ Используемые технологии

### Модель
- **Базовая модель:** [Qwen/Qwen3-1.7B](https://huggingface.co/Qwen/Qwen3-1.7B)
- Тип: Каузальная языковая модель
- Параметры: 2.04B

### Датасет
- **Источник:** [t-tech/T-Wix](https://huggingface.co/datasets/t-tech/T-Wix)
- **Размер:** 427,843 примера (после фильтрации)
- **Язык:** Русский
- **Формат:** Диалоги (messages)

### Метод дообучения
- **SFT (Supervised Fine-Tuning)** — обучение на парах инструкция-ответ
- **LoRA (Low-Rank Adaptation)** — параметрически-эффективное дообучение
  - Ранг (r): 8
  - Alpha: 16
  - Target modules: all-linear
  - Dropout: 0.05

### Библиотеки
- `transformers` — загрузка и инференс моделей
- `peft` — LoRA адаптеры
- `trl` — SFTTrainer
- `datasets` — работа с датасетами
- `evaluate` — метрики качества
- `matplotlib` — визуализация

## 📊 Метрики оценки

### Perplexity
Основная метрика качества модели. Показывает, насколько хорошо модель предсказывает следующий токен.
- **Чем ниже, тем лучше**
- Baseline: 4.62 → Finetuned: 2.95 (улучшение на 36%)

### ROUGE (Recall-Oriented Understudy for Gisting Evaluation)
Оценивает совпадение n-грамм между сгенерированным и эталонным ответами.
- **ROUGE-1:** совпадение униграмм
- **ROUGE-L:** совпадение по наибольшей общей подпоследовательности (LCS)

### BLEU (Bilingual Evaluation Understudy)
Оценивает качество машинного перевода и генерации текста.
